# MeCab_accent_tool

[日本語](README.md) | **English**

A standalone tool for adding and managing accent information in MeCab user dictionaries.

---

## Purpose

This tool assigns accent types to MeCab word dictionary entries to achieve accurate accent in Japanese TTS (Text-to-Speech).

### Why is this needed?

Standard MeCab (ipadic) **does not include accent information**.  
To correctly pronounce proper nouns and technical terms in Japanese TTS,  
a MeCab user dictionary (`.dic`) with accent type per word is required.

### What this tool can do

- **Manual accent registration**: Enter surface form, reading, and accent type
- **Auto accent prediction**: Automatically predict accent type using pyopenjtalk-plus / marine
- **Bulk ipadic processing**: Process all ipadic CSV files and save accents to DB
- **MeCab user dictionary build**: Export CSV → compile with `mecab-dict-index`
- **Accent test**: Analyze text with the compiled dictionary and verify

### Integration

Use alongside [Qwen3-TTS-JP-MeCab](https://github.com/mark10als/Qwen3-TTS-JP-MeCab).  
The `mecab_accent.dic` generated by this tool is auto-detected by Qwen3-TTS-JP-MeCab.

## Installation

### Step 1: Install MeCab (required, separate)

1. Download and install from:  
   👉 **https://github.com/ikegami-yukino/mecab/releases**  
   (Select `mecab-64-*.exe`; choose **UTF-8** for character encoding during installation)

2. Verify installation:
   ```cmd
   mecab --version
   ```

3. Default installation path:
   ```
   C:\Program Files\MeCab\bin\mecab-dict-index.exe   ← compile tool
   C:\Program Files\MeCab\dic\ipadic\                ← ipadic dictionary + CSV source
   ```

### Step 2: Clone the repository

```bash
git clone https://github.com/mark10als/MeCab_accent_tool.git
cd MeCab_accent_tool
```

### Step 3: Install required packages

Double-click `install_packages.bat`, or manually:

```cmd
:: Run with system Python
python -m pip install "gradio>=4.0"
python -m pip install "mecab-python3>=1.0"
python -m pip install pyopenjtalk-plus

:: marine requires PYTHONUTF8=1 to avoid encoding errors on Windows
set PYTHONUTF8=1
python -m pip install marine
set PYTHONUTF8=
```

Verify installation:

```cmd
python -c "import gradio; print('gradio:', gradio.__version__)"
python -c "import MeCab; print('MeCab: OK')"
python -c "import pyopenjtalk; print('pyopenjtalk-plus: OK')"
python -c "import marine; print('marine: OK')"
```

## Operation Guide

### Tab ① Add/Edit Words

Manually register proper nouns and technical terms.

| Field | Description |
|---|---|
| Surface form | Kanji/original text (e.g., `伝の心`) |
| Reading (hiragana) | Pronunciation in hiragana (e.g., `でんのしん`) |
| Accent type | Numeric value (`0`=flat, `1`=head-high, `N`=falls after N-th mora) |
| Part of speech | Select from dropdown |

**"Auto predict with pyopenjtalk" button**: After entering the reading, click to auto-fill the accent type.  
**"Add/Update" button**: Register to DB.

Accent type meanings:

| Type | Name | Example (5 mora) | Notation |
|---|---|---|---|
| 0 | Flat (Heiban) | L H H H H | お↑かねもち |
| 1 | Head-high (Atamadaka) | H L L L L | あ↓たま |
| 2 | Mid-high type 2 | L H L L L | い↑の↓ち |
| 3 | Mid-high type 3 | L H H L L | で↑んの↓しん |
| N (=mora count) | Tail-high (Odaka) | L H H H H↓ | お↑とこ (falls at end) |

### Tab ② Search / List

- Search registered entries by surface form, part of speech, and review status
- Delete entries or change "reviewed" flag
- Bulk import from `user_dict.json` (existing dictionary from Qwen3-TTS-JP-MeCab)

**Import procedure**:
1. Enter the file path in "user_dict.json path"
2. Click "Import"
3. Existing entries are imported into the DB

### Tab ③ Bulk ipadic Processing

Process all ipadic CSV files and save accents for all words to the DB.

> ⚠️ **Processing time**: Processing the entire ipadic (~400,000 words) takes several hours.  
> Use the "Nouns only" filter to process only the required parts of speech.

1. Select files with checkboxes ("Select all" / "Nouns only" buttons available)
2. Filter by part of speech (empty = all)
3. Click "▶ Start batch processing"
4. Monitor progress in the log

### Tab ④ Export / Compile

Convert DB entries to a MeCab user dictionary.

1. **"① Generate CSV"**: Export DB contents to 14-field CSV
2. **"② Compile to MeCab .dic"**: Generate `.dic` file using `mecab-dict-index`

Output files:
```
output/
  mecab_accent.csv   ← 14-field CSV (intermediate file)
  mecab_accent.dic   ← compiled MeCab user dictionary
```

After successful compilation, copy `output/mecab_accent.dic` to the Qwen3-TTS-JP-MeCab project root for automatic detection.

### Tab ⑤ Accent Test

Analyze text using the compiled `.dic` and verify accent.

- Enter text and click "Accent Analysis"
- Words with accent type registered in MeCab dictionary: displayed with that value
- Unregistered words: accent predicted by pyopenjtalk

## Data Format

### DB Schema (SQLite)

Stored in `data/accent.db`:

```sql
CREATE TABLE entries (
  id           INTEGER PRIMARY KEY,
  surface      TEXT,       -- surface form (kanji)
  reading_kata TEXT,       -- reading (katakana)
  pos          TEXT,       -- part of speech
  accent_type  INTEGER,    -- accent type (0=flat, 1=head-high, N=falls after N-th mora)
  reviewed     INTEGER,    -- reviewed flag (1=reviewed)
  source       TEXT,       -- source ("manual"/"user_dict.json"/CSV filename)
  ipadic_csv   TEXT        -- original ipadic CSV filename
);
```

### CSV Format (14-field ipadic extension)

```
surface,left_id,right_id,cost,pos,pos2,pos3,pos4,conj_type,conj_form,base,reading,pronunciation,accent_type
伝の心,1288,1288,5000,名詞,固有名詞,一般,*,*,*,伝の心,デンノシン,デンノシン,3
```
